## Featured Projects

### AI Quant Research Lab

A tested quantitative research workflow for evaluating trading strategy ideas using backtesting, performance metrics, experiment tracking, robustness checks, and agentic research workflows.

- Built with Python, pandas, NumPy, matplotlib, pytest, and yfinance
- Includes strategy backtesting, transaction cost modelling, Sharpe ratio, maximum drawdown, and multi-asset analysis
- Includes a local research-agent workflow for generating hypotheses, critiques, reports, and reproducible artifacts
- 115 passing tests

Repository: [AI Quant Research Lab](https://github.com/fadil-uddin/Ai-Quant-Research-Lab)

---

### Irish Rental Affordability Analysis

A public-data analysis project using RTB/CSO Irish rental data to study county-level rent trends, regional affordability pressure, and Dublin versus non-Dublin rent differences.

- Cleaned and analysed a 976,740-row quarterly rent dataset
- Produced six charts, key findings, an executive summary, and a consulting-style deck outline
- Found average county-level rent rose from EUR 778 in 2007Q4 to EUR 1,336 in 2025Q4
- Includes 7 passing tests

Repository: [Irish Rental Affordability Analysis](https://github.com/fadil-uddin/irish-rent-analysis)

---

### Chess AI Bot

A custom chess AI project using neural networks and game-playing logic, with a full-stack web interface for playing against the trained model.

- Built with Python, PyTorch, NumPy, Flask, React, and Docker
- Trained on Stockfish self-play and public chess datasets
- Applied game theory and reinforcement learning concepts to decision-making
- Deployed as an interactive web app

Repository: [Chess AI Bot](https://github.com/fadil-uddin/Chess-AI-Bot)
